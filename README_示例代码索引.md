## 详细说明

### example_01_中介调节_300.py
**最全面的综合示例**

- **样本量**：300
- **维度**：ABCD 4个维度，每维度7题
- **控制变量**：EFGHI 5个单题控制变量
- **适用场景**：
  - 信度：α > 0.80
  - 效度：AVE > 0.50，CR > 0.70
  - EFA：KMO > 0.60，4因子结构清晰
  - CFA：CFI>0.90，RMSEA<0.08
  - 相关性：ABCD两两相关显著
  - 控制变量：多选项控制变量生成
  - 中介效应：B 在 A→D 中负向中介
  - 调节效应：C 负向调节 A→B
  - 有调节的中介：C 负向调节 B 的中介作用
- **推荐用途**：需要控制变量+中介+调节的综合研究

## 使用建议

1. **先看需求复杂度**：简单需求选基础模板，复杂需求选综合模板
2. **看样本量和维度数**：选择接近的示例
3. **看量表级数**：5级选5级示例，7级选7级示例
4. **看特殊需求**：控制变量、均值控制、高阶因子等
